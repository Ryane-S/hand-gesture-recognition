# ✋ Hand Sign Alphabet Recognition

## Project Overview

A deep learning system that classifies hand sign gestures corresponding to alphabetic characters (A-Z) using convolutional neural networks. The model employs transfer learning with MobileNetV2 architecture, trained on 7,800 custom-collected hand gesture images.
